# 미션 4 기록: 등급별 영화 편수

- 사용한 AI: Codex (GPT-6 계열, 이 대화)
- 주요 대화 캡처 파일명: 아직 저장하지 않음
- 기능 추가본 브라우저 화면: `등급별편수_동작화면.jpg` (S·A 각각 1편 표시)
- 더한 기능과 고른 이유: S·A·B·C 등급별 영화 편수. 배치가 많아지면 어느 등급에 몇 편이 있는지 한눈에 확인하려고 선택했다.

| 받은 파일 | 맞지 않은 완성 기준 | 한 일 |
| --- | --- | --- |
| `샘플_원본/샘플/영화_원본.html` | 새 기능인 등급별 편수가 없다 | 원본을 보존하고 `영화_기능추가.html`을 만들었다 |
| `영화_기능추가.html` | 확인한 범위에서는 없음 | 새 기능과 기존 이동·새로고침 기능을 확인해 완성본으로 정했다 |

## 기준과 변경

- 기준 파일: `샘플_원본/샘플/영화_원본.html`. 원본은 보존했다.
- 새 파일: `영화_기능추가.html`.
- 추가 기능: S·A·B·C 등급 버튼 안에 해당 등급의 영화 편수를 표시한다. 기존 선택·이동·추가·저장·초기화 동작은 유지한다.
- 기획서에 화면 동작과 편수의 완료 기준을 추가했다.

## 한 번씩 확인한 결과

| 단계 | 예상 | 브라우저에서 확인한 결과 |
| --- | --- | --- |
| 원본에서 공백이 있는 `센과 치히로의 행방불명`을 A로 이동 | A 칸에 나타남 | 통과 |
| 원본 새로고침 | A 배치가 유지됨 | 통과 |
| 기능 추가 파일을 처음으로 초기화 | S·A·B·C 모두 0편 | 통과 |
| `기생충`을 S로 이동 | S가 1편, 나머지 0편 | 통과 |
| 기능 추가 파일 새로고침 | S의 영화와 1편 유지 | 통과 |

추가 기능은 `render()`가 실행될 때 현재 `state.items`를 기준으로 다시 계산한다. 따라서 저장된 숫자를 따로 관리하지 않는다.
