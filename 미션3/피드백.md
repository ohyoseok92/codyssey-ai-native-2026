# 민수 님께 드리는 피드백

기본 영화 8개를 직접 S 칸으로 옮겨 봤습니다. 모두 이동했고, 등급별 색과 ‘몇 편 나눔’ 표시 덕분에 현재 상태를 읽기 쉬웠습니다.

고치면 좋을 점은 두 가지입니다.

1. **저장**: 영화를 옮기고 새 카드를 추가한 뒤 파일을 다시 열자 배치와 추가 카드가 사라졌습니다. 기획서의 재열기 후 보존 기준에 맞게, 변경할 때 브라우저에 저장하고 다시 열 때 복원해 주세요.
2. **빈 제목**: 제목 칸에 공백만 입력하고 ‘추가’를 누르자 이름 없는 카드가 생겼습니다. 앞뒤 공백을 제거한 뒤 내용이 없으면 추가하지 않고 안내를 보여 주세요.

동료가 말한 긴 드래그 거리도 이해됐습니다. 현재 작동하는 ‘카드를 누른 뒤 등급을 누르기’ 방법을 목록 가까이에 안내하면 휴대폰에서 더 쉽게 옮길 수 있겠습니다.

한편 ‘처음으로를 눌러도 추가 카드가 남는다’는 AI 검토 의견은 제 시험에서는 재현되지 않았습니다. `새영화`를 추가하고 ‘처음으로’를 누르자 카드가 사라졌습니다. 휴대폰에서 불편했던 다른 장면은 어떤 기기와 행동이었는지 더 물어본 뒤 판단하면 좋겠습니다.
