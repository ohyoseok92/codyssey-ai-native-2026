# 미션 3 기록

브라우저 재현 화면: `민수_중복제목_재현.jpg` (기본 `기생충`과 새로 추가한 같은 제목이 함께 보임).

받은 피드백을 읽기 전에 `민수_기획서.md`와 `민수_영화티어리스트.html`을 열어 직접 시험했다. 기본 영화 8개는 카드 선택 후 S 칸으로 모두 이동했다. 공백 제목을 입력해도 빈 제목 카드가 추가됐고, `기생충`을 다시 입력하면 같은 제목의 카드가 하나 더 생겼다. 파일을 다시 열자 이동 기록과 추가 카드가 사라졌다. 별도로 추가한 `새영화`는 ‘처음으로’를 누르면 제거됐다.

| 받은 의견 | 직접 확인한 결과 | 판단 | 이유 또는 되물을 내용 |
|---|---|---|---|
| AI: 저장 기능이 없어 다시 열면 배치가 사라진다 | 8개를 S로 이동하고 새 카드를 추가한 뒤 다시 열자 8개가 미분류로 돌아갔다 | 반영 | 기획서의 재열기 후 보존 기준을 충족하지 못한다 |
| AI: ‘처음으로’가 직접 추가한 영화를 지우지 않는다 | `새영화`를 추가하고 ‘처음으로’를 누르자 카드가 사라졌다 | 보류 | 직접 시험한 결과와 다른 지적이다 |
| AI: 빈 제목을 막지 않는다 | 공백만 입력하고 추가하자 제목 없는 카드가 생겼다 | 반영 | 빈 카드는 목록에서 구별하기 어렵다 |

| 동료: 카드 옮기는 방법이 처음에 헷갈린다 | 카드 선택 뒤 등급 버튼을 누르면 이동하지만, 안내가 처음 쓰는 사람에게 충분한지는 확인되지 않았다 | 되묻기 | 어느 단계에서 멈췄는지, 안내 문구를 보았는지 묻는다 |

| 동료: 카드 색이 칙칙하다 | 취향에 관한 의견이다 | 보류 | 기획서의 기능 조건과 직접 연결되지 않는다 |
| 동료: 포스터 사진이 있으면 좋다 | 현재 기획서의 필수 자료에 포스터가 없다 | 보류 | 이미지 출처와 이용 권한부터 정해야 한다 |

## 직접 찾은 추가 문제

기존 제목 `기생충`을 다시 추가하면 같은 제목의 카드가 중복된다. 기획서에는 중복 금지 조건이 없으므로 민수에게 정책을 먼저 정하자고 제안한다.

## 민수 님께 보낼 피드백 초안

잘된 점: 기본 영화 8개를 각각 선택해 S 칸으로 옮겼을 때 모두 이동했고, 등급별 색과 ‘8편 중 몇 편 나눔’ 표시로 현재 상태를 읽기 쉬웠습니다.

고치면 좋을 점

1. 본 것: 영화를 옮기고 새 카드를 추가한 뒤 파일을 다시 열었더니 모두 처음 상태로 돌아왔습니다.  
   기준: 기획서의 ‘같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남는다’.  
   제안: 변경 뒤 브라우저에 저장하고, 열 때 저장된 목록을 복원해 주세요.
2. 본 것: 제목 칸에 공백만 넣고 ‘추가’를 누르자 이름 없는 카드가 생겼습니다.  
   기준: 제목을 입력해야 영화를 구별할 수 있습니다.  
   제안: 앞뒤 공백을 제거한 뒤 빈 제목이면 카드를 만들지 말고 안내를 보여 주세요.
3. 본 것: 카드 목록이 화면 아래에 있어 위쪽 S 칸까지 끌어 놓으려면 화면을 길게 이동해야 합니다.  
   기준: 동료가 직접 사용하며 겪은 불편입니다.  
   제안: 이미 동작하는 ‘카드 선택 후 등급 누르기’를 목록 가까이에 짧게 안내하고, 터치 화면에서도 쉽게 찾을 수 있게 해 주세요.

AI 검토 중 ‘처음으로가 추가 영화를 지우지 않는다’는 지적은 재현되지 않았습니다. 확인한 환경에서는 추가 카드가 제거됐습니다. 휴대폰 사용의 다른 불편은 구체적인 행동을 먼저 물어보면 좋겠습니다.
