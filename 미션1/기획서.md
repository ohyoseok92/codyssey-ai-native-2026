# 내 영화 티어리스트

## 대상 사용자

- 본 영화를 S·A·B·C로 나누고 싶은 나와 친구.

## 사용 목적

- 8편의 샘플 영화를 취향대로 배치하고, 다른 영화를 추가해 계속 정리한다.

## 화면 구성과 동작

- S·A·B·C 등급 칸과 미분류 칸에 영화를 카드로 보여 준다.
- 카드를 누른 뒤 등급을 누르거나 카드를 끌어서 옮긴다.
- 영화 제목을 입력해 새 카드를 추가한다.
- 배치와 추가한 영화는 이 브라우저에 자동 저장한다.
- 처음으로 버튼은 기본 영화 8편을 모두 미분류로 돌린다.

## 필요한 자료

- `기생충`, `인터스텔라`, `라라랜드`, `센과 치히로의 행방불명`, `어벤져스: 엔드게임`, `범죄도시`, `타이타닉`, `토이 스토리`.

## 완료 기준

- 영화는 한 번에 한 등급에만 나타난다.
- 클릭 이동과 드래그 이동이 가능하다.
- 빈 제목과 중복 제목은 추가되지 않는다.
- 새로고침 후에도 배치가 남고, 처음으로 누르면 기본 상태가 된다.
- 좁은 화면에서도 카드와 조작 버튼이 잘리지 않는다.
- HTML 파일 하나만으로 실행된다.

## 한계 및 비목표

1. 저장 내용은 다른 기기와 동기화하지 않는다.
2. 포스터·평점 등 외부 영화 자료는 가져오지 않는다.
3. 파일을 공유해도 개인의 브라우저 저장 내용은 함께 전달되지 않는다.

## 기획 대화

- 사용자에게 등급과 조작 방식, 저장 방식을 물었다. 사용자는 S·A·B·C와 미분류, 클릭·드래그 이동, 브라우저 자동 저장을 선택했다.
- AI 서비스·모델: OpenAI Codex (GPT-6 계열, 이 대화). 실제 세부 모델 표시는 확인 필요.
