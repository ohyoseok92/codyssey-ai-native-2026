# 제작·검증 기록: 나의 영화 기록

## 기준

- 미션 6 결과 `영화기록_v1.html`과 미션 5 기획서를 기준으로, 한 번에 한 항목씩 바꾸고 브라우저에서 확인했다.
- 최종 결과물은 `영화기록_최종.html`이다. 미션 7 `기획서.md`에는 추가 동작을 반영했다.

## 수정 기록 1 — 검색 결과 수

- 직접 써 보니 검색 중에도 상단에는 전체 기록 수만 표시되어 현재 몇 편이 일치하는지 알기 어려웠다.
- 요청: 검색어가 있을 때 목록 위에 일치한 편수를 표시하고, 검색을 지우면 이 줄도 비운다.
- 결과물: `영화기록_수정1.html`.
- 확인: `기생` 검색 시 기생충 1건과 `검색 결과 1편`이 나타났다. 통과.

## 수정 기록 2 — 삭제 되돌리기

- 첫 버전은 삭제 버튼을 한 번 누르면 곧바로 기록이 사라져 오조작을 되돌릴 수 없었다.
- 요청: 마지막 삭제를 같은 화면에서 취소할 수 있게 한다.
- 결과물: `영화기록_수정2.html`.
- 확인: 기생충 삭제 후 0건·`삭제 취소` 버튼을 확인했다. 버튼을 누르자 1건·평균 4.0점으로 돌아왔다. 통과.
- 범위: 같은 페이지를 열어 둔 동안 마지막 삭제 1건을 되돌린다. 새로고침 후 복구는 지원하지 않는다.

## 수정 기록 3 — 수정 중 Esc 취소

- 수정 버튼을 누르면 위쪽 입력칸으로 이동한다. 키보드만 쓰는 경우 취소 버튼까지 다시 이동해야 했다.
- 요청: 수정 중 Esc를 누르면 저장하지 않고 편집 상태를 닫는다.
- 결과물: `영화기록_최종.html`.
- 확인: 기생충 제목을 임시로 바꾸고 Esc를 누르니 `기록 저장` 상태로 돌아왔고 목록 제목은 기생충 그대로였다. 통과.

## 기존 기능 회귀 확인

- 미션 6에서 추가·평점 평균·새로고침 저장·제목 검색·수정·삭제를 브라우저로 확인했다.
- 최종 파일에서도 두 영화를 추가해 2편·평균 3.0점을 확인했고, 새로고침 후 두 기록이 유지됐다. 검색·수정·삭제는 앞선 버전에서 각 변경 직후 확인했다.
- 최종 브라우저 화면: `최종_브라우저_검증.jpg`.

## 실제 사용자 테스트

- 다른 사람의 실제 테스트 참여와 피드백: 아직 받지 못했다.
- 참여자의 행동·질문·개선 제안은 추정하거나 만들어 적지 않는다.
- 다른 사람이 제목·평점·한줄평 입력, 검색, 수정, 삭제 취소를 직접 사용한 후 의견을 주면 이 부분을 기록하고 개선 1건을 반영한다.
