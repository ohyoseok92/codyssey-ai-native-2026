# 나의 영화 기록

## 대상 사용자

- 본 영화를 간단히 기록하고 다시 찾으려는 나.

## 사용 목적

- 영화 제목, 5점 만점 평점, 한줄평을 한곳에 남기고 검색한다.

## 화면 구성과 동작

- 상단에 제목·평점·한줄평 입력칸과 저장 버튼을 둔다.
- 아래에 제목 검색칸과 기록 목록을 둔다.
- 기록을 추가하거나 기존 기록을 수정·삭제할 수 있다.
- 입력과 변경 내용은 이 브라우저에 자동 저장한다.
- 화면 폭이 좁아져도 입력과 목록을 사용할 수 있다.

## 필요한 자료

- 사용자가 직접 입력하는 영화 제목, 평점, 한줄평. 외부 영화 정보는 사용하지 않는다.

## 완료 기준

- 제목·평점·한줄평을 입력하면 목록에 1건이 생긴다.
- 제목이나 한줄평이 비어 있으면 저장하지 않고 이유를 보여 준다.
- 평점은 1~5점 중 하나만 선택할 수 있다.
- 기존 기록을 수정하거나 삭제하면 목록에 바로 반영된다.
- 검색어를 입력하면 제목에 맞는 기록만 보이고, 검색어를 지우면 전체가 보인다.
- 검색 중에는 일치한 기록의 편수를 보여 준다.
- 삭제 직후에는 화면의 ‘삭제 취소’로 마지막 삭제를 되돌릴 수 있다.
- 기록 수정 중 Esc 키를 누르면 저장하지 않고 수정을 취소한다.
- 파일을 새로 열어도 같은 브라우저의 기록이 남는다.
- 외부 파일·로그인·서버 없이 HTML 파일 한 장으로 동작한다.

## 추가 기능

- 기록 수와 평균 평점 표시.

## 한계 및 비목표

1. 기록은 현재 브라우저에 저장되며 다른 기기로 자동 동기화하지 않는다.
2. 포스터·상영 정보 등 외부 영화 데이터는 가져오지 않는다.
3. 여러 사람이 동시에 편집하거나 계정을 만들어 공유하지 않는다.

## 검증 방법

- 테스트용 제목·평점·한줄평을 직접 입력하고 목록의 내용과 대조한다.
- 두 기록의 평점이 4점과 2점이면 평균이 3.0점인지 손으로 계산해 확인한다.
- 빈칸, 검색, 수정, 삭제, 새로고침을 하나씩 확인한다.

## 기획 대화

- 사용자에게 주제와 기록 항목을 물었다. 사용자는 ‘영화 기록 페이지’, ‘제목·평점·한줄평’이라고 답했다.
- 자동 저장과 추가·수정·삭제·검색을 물었다. 사용자는 모두 포함하라고 답했다.
- AI 서비스·모델: OpenAI Codex (GPT-6 계열, 이 대화). 실제 세부 모델 표시는 확인 필요.
